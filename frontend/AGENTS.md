# Instrucciones del frontend
- Expo SDK 58, React Native y TypeScript.
- Usar Expo Router; rutas en src/app.
- Interfaz, comentarios y nombres funcionales en español.
- Consultar ../docs/API-BACKEND.md antes de integrar rutas o DTO.
- El backend es la fuente de verdad de estados, permisos, saldos, retos, reservas y sorteo.
- No añadir Socket.IO mientras el backend no publique un canal compatible.
- Instalar módulos nativos mediante npx expo install.
- No ejecutar pruebas, compilaciones, instalaciones, migraciones ni despliegues sin autorización.
